How Switch works

Each Mac reads its own Codex and Claude sign-ins from the official apps every 10 minutes. Nothing here runs a model or spends usage. A subscription signed in on several Macs shows once, with the newest reading. The big number on a card is what is left in its tightest window.

Balanced picks the least-used ready account, Reset first the one whose limit resets soonest, Spend first the most-used one. The policy picks the account for runs started with specweave-switch run and for Studio's Draft using capacity policy. Chats that are already running keep their account. Pin forces one account on that Mac; Unpin goes back to the policy.

Each Mac has 4 Codex and 3 Claude slots. Add another Codex account with specweave-switch account login codex-2 on that Mac. Extra Claude slots stay locked because Claude Code keeps one login per Mac, so a further Claude subscription needs its own Mac or a CLIProxyAPI hub (Studio reads hub accounts under Usage → Limits).

Credits and banked resets are paid overflow used only after an account's windows run out. Switch never spends them. Copilot lists every account signed in to gh or Copilot CLI on any Mac; one GitHub AI credit is $0.01.
