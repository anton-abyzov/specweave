How Switch works

Each Mac reads its own Codex and Claude sign-ins directly from the official apps and refreshes every 10 minutes. Bars show what is left in each window. Nothing here runs a model or spends usage.

Balanced picks the least-used account, Reset first the one whose limit resets soonest, Spend first the most-used one. The choice applies to new runs started through Switch and to the account Studio suggests for a new chat. Running sessions keep their account. Pin forces one account on that Mac.

Each Mac has 4 Codex and 3 Claude slots. Add another Codex account on a Mac with specweave-switch account login codex-2. Extra Claude slots stay locked because Claude Code keeps one login per Mac.

Credits under an account are paid overflow used only after its windows run out: the Codex balance and banked resets, and Claude extra usage. Other subscriptions lists GitHub Copilot for every account signed in to gh or Copilot CLI on any Mac; a GitHub credit is $0.01. The proxy dot counts accounts signed in to CLIProxyAPI, which is not a credits source.
