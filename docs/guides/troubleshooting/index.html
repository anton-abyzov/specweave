Common Issues​

"Claude Code Keeps Crashing"​

Most crashes are due to context explosion. See the prevention strategies.

Quick fix:

export SPECWEAVE_DISABLE_HOOKS=1
rm -f .specweave/state/.hook-*

"Hooks Not Running"​

Check if hooks are disabled:

echo $SPECWEAVE_DISABLE_HOOKS
# If "1", hooks are disabled

# Re-enable
unset SPECWEAVE_DISABLE_HOOKS

"Sync Throttled"​

SpecWeave limits API calls to prevent rate limiting. Wait 60 seconds or force sync:

"Sync progress"

Getting Help​

  1. Check this documentation
  2. Search GitHub Issues
  3. Report new issues with:
    • SpecWeave version
    • Node.js version
    • Steps to reproduce
    • Error messages
