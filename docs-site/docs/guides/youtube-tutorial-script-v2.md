> S-level: how well it's been VERIFIED. S0 is unscanned. S1 passed automated pattern checks — 29 regex patterns for destructive commands, data exfiltration, code execution. S2 passed LLM intent analysis AND scored 80+. S3 is all of that PLUS a cryptographic signature.
>
> When you install from verified-skill.com, you see E2/S3. You know exactly what you're getting."

### Quality Gates

**[SCREEN: /sw:done execution]**

> "When tasks complete, `/sw:done` runs automatically. No manual trigger needed — the workflow closes itself.
>
> Three gates:
>
> **Gate 1 — Grill**: An adversarial review agent loads every acceptance criterion and verifies independently. 'The implementer finished suspiciously quickly — verify everything.' AC-level pass/fail in the report.
>
> **Gate 2 — Judge**: LLM judges the code quality, architecture choices, test coverage. Written report.
>
> **Gate 3 — PM Validation**: Did we build the right thing? Does it match the spec?
>
> If any gate fails, the increment stays open. No premature closure. And every gate result is permanent — stored in `.specweave/increments/` forever."

**[EXCALIDRAW: AI Judge Architecture]**

```
┌──────────────────────────────────────────────────────────┐
│                DRAW IT AI JUDGE PIPELINE                  │
├──────────────────────────────────────────────────────────┤
│                                                           │
│  Drawing A + Drawing B + Target Concept                   │
│                ↓                                          │
│  Layer 1: Visual Similarity (CLIP embeddings)             │
│  Layer 2: Semantic Match (VLM description)                │
│  Layer 3: Creativity Factor (novelty scoring)             │
│                ↓                                          │
│  Weighted Score: A vs B                                   │
│                ↓                                          │
│  Winner + Explanation (in plain language)                 │
│                                                           │
└──────────────────────────────────────────────────────────┘
```
