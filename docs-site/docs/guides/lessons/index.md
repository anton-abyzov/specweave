## The `:next` Navigation System

Throughout these lessons, you'll see the `:next` prompt. This mirrors SpecWeave's core workflow command:

```bash
# In SpecWeave
/specweave:next   # "What should I do next?"

# In these lessons
:next             # "Take me to the next lesson"
```

**The philosophy**: Never be stuck wondering "what now?" — the system guides you.
