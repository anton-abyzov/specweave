# Learning Bridges

**Smooth transitions between academy parts.**

Each bridge helps you:
1. **Consolidate** what you learned in the previous part
2. **Connect** concepts to what comes next
3. **Preview** skills you'll develop

## Why Bridges Matter

```
Part N skills → Gap → Part N+1 skills
```

Without bridges, you might wonder:
- "Why do I need this?"
- "How does this connect to what I learned?"
- "Am I ready for the next part?"

Bridges answer these questions.

---

## How to Use Bridges

**Before moving to the next part:**
1. Read the bridge guide
2. Complete the self-assessment
3. Review any concepts you're unsure about
4. Try the bridge exercises

**If you're struggling:**
- Go back to the previous part's lessons
- Don't skip — each part builds on the last
