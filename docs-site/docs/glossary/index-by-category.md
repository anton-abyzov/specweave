# Glossary by Category

Explore SpecWeave terminology organized by related concepts.

---

## Increment Files

The core files that make up every SpecWeave increment.

- [spec.md](/docs/glossary/terms/spec-md) - Primary specification document with user stories and acceptance criteria
- [plan.md](/docs/glossary/terms/plan-md) - Technical architecture and implementation strategy
- [tasks.md](/docs/glossary/terms/tasks-md) - Implementation checklist with BDD test plans
- [metadata.json](/docs/glossary/terms/metadata-json) - Increment status, timestamps, and external tool integration
- [AC-ID](/docs/glossary/terms/ac-id) - Unique acceptance criteria identifiers (AC-US1-01)
- [Increments](/docs/glossary/terms/increments) - Focused units of work (spec.md, plan.md, tasks.md)
