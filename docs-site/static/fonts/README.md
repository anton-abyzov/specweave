# Website fonts

JetBrains Mono and Schibsted Grotesk retain the existing website typography. These variable WOFF2 files were downloaded from Google Fonts on October 22, 2026, with all supplied language subsets and `font-display: swap`. The CSS import makes Docusaurus emit content-hashed, same-origin font assets.

Sources: https://fonts.google.com/specimen/JetBrains+Mono and https://fonts.google.com/specimen/Schibsted+Grotesk.

Licenses: `jetbrainsmono-OFL.txt` and `schibstedgrotesk-OFL.txt` in this folder, from the corresponding https://github.com/google/fonts/tree/main/ofl font directories. Both use SIL Open Font License 1.1. The files are unmodified.
