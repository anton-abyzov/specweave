What changed, and why.

A clearer work board

Persistent intent cards, drag-and-drop, accessible move controls, linked increments and live task progress. See the outcome before opening the details.

Evidence survives the session

Portable handoffs and separate harness, model, effort and provider records. Local files refresh the dashboard without model calls. Switch tools without rebuilding context.

Honest completion and costs

Moving a card to Done does not invent verification. Unknown usage stays unknown; estimates remain distinct from bills. A green card should not hide unfinished checks.

Focused skills and safer maintenance

Source, security and usefulness get separate explanations. vskill cleanup now respects project and global ownership. Keep useful expertise and preserve unrelated plugins.

Two redesigned websites

Layered navigation, mobile layouts, original Kie.ai graphics, clearer documentation and repaired video seeking. Understand the product and reach the next action quickly.

Optional enterprise connections

GitHub, Jira and Azure DevOps remain available. Pull failures are visible and successful partial results survive. Fit an existing team workflow without requiring one.

Start locally: install with npm install -g specweave, then run specweave dashboard from your project. Open Studio with npx vskill@latest studio. Restart existing processes after upgrading.

Less machinery. Same durable record.

Default hooks reduced to SessionStart and Stop. Routine Stop events return early; automatic continuation remains opt-in. The increment skill respects autonomous authorization instead of forcing a plan-mode interruption.

48 obsolete installation locations removed, with backups
  • 13 unconditional greeting installations.
  • 6 leaked test-fixture installations.
  • 14 broken Postiz wrappers; working Postiz retained.
  • 12 obsolete Obsidian overrides; current global workflow retained.
  • 1 duplicate cold-email skill, 1 broken Remotion link and 1 discoverable archived Excalidraw installation.

These are installation locations across multiple tools, not 48 distinct skills. Domain, App Store, release, design and other useful expertise remain.

Known limits and what this release does not claim

The full docs suite still has 10 baseline failures. Five private-workspace E2E cases remain unresolved, and an LSP timing benchmark is intermittent. Existing repository-wide TypeScript diagnostics remain. Passing product checks do not mean every repository check is green.

Universal transcript-to-intent assignment, full conflict-resolving tracker synchronization, fair cross-harness quality rankings and calibrated completion forecasts are not shipped. The business hypothesis is less re-explaining and clearer evidence when switching tools; paid demand is not yet proven.
