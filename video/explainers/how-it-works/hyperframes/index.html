SpecWithCode
One coordinator for the coding agents you already pay for.
spec-weave.com/studio
Claude Code in one terminal.
Codex in another.
And you in the middle,
copying context between them all day.
You paste the goal,
the error, what the other agent decided.
The agents write the code.
You do the routing.
SpecWithCode is a free Mac app for the
coding agents you already pay for:
Claude Code, Codex,
Grok Build, Cursor,
OpenCode, Copilot, Antigravity and Pi.
It takes the routing off your hands.
Add a project over a real folder.
It gets one coordinator:
a conversation that routes and tracks the work,
while worker threads write the code.
Describe the work once.
Quick questions it answers itself.
Code changes, long research and tool work go
to worker threads it starts.
Here it started two workers:
Claude on the greeting,
and Codex on the CI workflow,
because the ask named Codex.
Each one gets a card and a link.
Follow-ups go to the worker already on that
area, so nothing is assigned twice.
When a worker finishes,
its report comes back on its own.
No polling, no pasting.
The coordinator and the workers have separate models.
Keep the coordinator on Claude Opus 5.5,
set a default worker model,
or name one in the ask,
like Codex here.
The usage chip shows one ring per subscription,
amber at 80 percent,
red at 95.
If one runs out,
the thread offers to continue on another signed-in provider.
For bigger work,
the Plan holds a short spec,
acceptance criteria and tasks,
and who owns each.
A worker can report a task done.
Only you make it Verified:
Run verification runs its check and keeps a receipt.
The agents write the code.
The coordinator routes it.
You review the results.
SpecWithCode is free,
with no account,
for Apple silicon Macs.
Get it at spec-weave.com/studio.
