With specweave auto-handoff on,
Claude Code sends its usage to SpecWeave.
Here we pass in a sample reading
of 95% of the 5-hour limit.
The guard says a handoff is
available, and work continues.
When you are ready,
tell Claude to hand off.
It runs specweave handoff with a reason,
releases its claim on T-02,
and writes handoff.md.
handoff.md says who stopped and
why, and which tasks are done.
It lists the uncommitted files,
with the full diff beside it,
and the exact next step.
Now open Codex in the same
repo and say "pick up".
It runs specweave pickup,
which reads the handoff
and records the pickup in
the ledger as codex@demo.
Pickup names the next task, T-02,
with its acceptance criterion,
its files and its test.
Codex claims it.
With the change in place,
task done --run runs the test again.
Only a passing test marks the task done,
and the ledger shows
that Codex finished it.
Next, specweave verify checks the
increment before you close it.
