Run one small change with codecs in spec with code. This
walkthrough prepares the task. It does not submit a provider
run.
In Settings, Providers, connect with ChatGPT or use an
existing Codex CLI login on the machine that runs the
project. Wait until the account and available models are
confirmed.
Open an example repository as a project. The main
conversation is the project coordinator. Check which machine
is doing the work.
Select Codex, an available model, and the approval mode you
intend to use. This tutorial does not require full access.
Give it one bounded task. Add a named greeting, keep the no
argument greeting working, and add tests for Goathe. Ask it
to describe the change before editing.
Read the proposed change, then ask it to implement. Review
any command approval rather than accepting it automatically.
Inspect the changed files and the actual test output. If a
check failed or was not run, keep that in the result. A
confident reply is not test evidence.
Finish with the change, its diff, and actual test evidence.
Use SpecWeave increments when you need a durable plan and
task record. They are optional for this first task.
