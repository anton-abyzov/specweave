Codex in SpecWithCode: plan, build, review.
In your repo, run specweave init.
It adds AGENTS.md and eleven SpecWeave skills.
Open SpecWithCode. In setup, keep this computer and click Continue.
On the Codex card, click Continue with ChatGPT,
or run codex login, then Use existing CLI.
The card says Ready to code.
Add the repo: the plus next to Projects, Local folder, then its path.
A new chat opens.
Pick Codex in the model picker, and set Full access for this demo.
Type a dollar sign, pick sw-increment, and describe the change.
Codex writes spec.md: acceptance criteria and a task with its files and test.
Then send sw-do.
Codex claims the task, changes the code, and runs the test.
The task is marked done only when the test passes.
Click Open diff to review the code, the test,
and the ledger line that records who finished the task.
Next, sw-done verifies and closes the increment.
