Codex in SpecWithCode: one task, planned, built and reviewed.
In your repo, run specweave init.
It adds AGENTS.md and seven SpecWeave skills, such as sw-increment and sw-do.
Open SpecWithCode and set this Mac up as your main machine.
On the Codex card, click Use existing CLI to reuse your Codex sign-in.
The card says Ready.
Add the repo: the plus next to Projects, Local folder, then its path.
The project opens on its coordinator.
Set Full access for this demo, describe the change, and send it.
The coordinator hands the work to a new thread.
The thread plans increment 1: acceptance criteria and one task with its test.
Then it changes the code and runs that test.
A task is done only when its test passes.
Open the thread to review it: the summary,
the verification and review reports, and every changed file in Open diff.
Increment 1 is verified and closed.
Next, run the same task with another agent.
