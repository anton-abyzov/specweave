Recorded with two disposable SpecWithCode 1.0.47 servers, a Mac and a Mac mini on one tailnet. The invitation line, the pairing code and the Mac mini's Tailscale address are blurred; the pairing code was made off camera with specwithcode pair. Navigation is sped up where marked. The narration is an AI voice.

All tutorials: spec-weave.com/tutorials
Add a second machine.
Both machines need Tailscale,
signed in to the same account,
with MagicDNS and HTTPS
certificates turned on.
On the new machine, here a Mac mini,
open Settings, then Connections.
Choose Invite this machine, give it
a name, and choose Make the line.
SpecWithCode publishes itself on the
Mac mini's private Tailscale name,
never on the public internet.
The line works like a password,
so it stays blurred here.
On your main machine, open
the same Connections page.
Paste the line under Add a
machine, and choose Add machine.
The main machine checks that
the address answers as that Mac,
then lists it as reachable.
Its address is blurred too.
Pick the most a worker there may do.
Version 1.0.47 also asks for a one-time
pairing code from the Mac mini,
made there beforehand
with specwithcode pair.
Then choose Allow workers. The card
now reads Allowed: Full access.
