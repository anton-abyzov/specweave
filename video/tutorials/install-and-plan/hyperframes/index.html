Install SpecWeave and
plan your first increment.
Install the CLI from npm
with npm i -g specweave.
It needs Node 20.12 or later.
specweave --version prints 3.1.0.
In your repo, run specweave init
with the Claude Code adapter.
It writes CLAUDE.md and AGENTS.md,
installs six SpecWeave skills,
and keeps its settings in
.specweave/config.json.
Now plan the work. Give
specweave create-increment a title.
It makes the folder
0001-personal-greeting,
with a spec.md to fill in.
Step one is Decide. At the
default level, critical,
your agent asks only the
decisions that are yours,
one at a time with a recommended answer.
Then fill in spec.md,
yourself or with the sw-increment skill:
the problem, and numbered acceptance
criteria that a test can check.
Decisions records what was asked,
what was defaulted, and what is open.
Each task names its acceptance
criterion, its files,
and the test that proves it.
Commit the plan, then
run specweave pickup.
It shows the increment,
the next task, T-01,
with its acceptance
criterion, files and test,
and the command that claims it.

and prove it with task done --run.
