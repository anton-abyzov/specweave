Claim, prove, verify and complete a task
with the SpecWeave CLI.
Start with specweave task claim T-01.
The claim goes into the
ledger as claude@demo,
so others see who owns the task.
It prints the acceptance
criteria, the files and the test.
With the change committed,
task done --run runs the test again.
Only a zero exit marks the task done,
with the output as evidence.
The full output is saved
in reports/task-T-01.txt:
the command, its exit code and
the time, then the test results.
Now try to close the increment
with specweave complete.
It refuses:
reports/verify.json is missing,
so it tells you to run
specweave verify first.
specweave verify runs the project's
test, lint and build scripts,
here only npm run test.
Both acceptance criteria are met,
because the task that covers them is done.
Its report, verify.md,
keeps the test output,
the criteria table, and
the task with its evidence.
verify.json beside it
is what complete reads.
Run specweave complete again.
The verify check passes, and
the increment is completed.
Next, hand the work to another
agent with specweave handoff.
