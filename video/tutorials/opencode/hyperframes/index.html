OpenCode in SpecWithCode: plan, build, review.
In your repo, run specweave init.
It adds AGENTS.md and eleven SpecWeave skills.
Sign OpenCode in to a model provider first:
run opencode auth login in a terminal.
Open SpecWithCode, then Settings, Providers.
Click Add provider, pick OpenCode, click Next twice, then Add instance.
Add the repo: the plus next to Projects, Local folder, then its path.
A new chat opens.
Pick OpenCode in the model picker, and set Full access for this demo.
Type a dollar sign, pick sw-increment, and describe the change.
OpenCode writes spec.md: acceptance criteria and a task with its files and test.
Then send sw-do.
OpenCode claims the task, changes the code, and runs the test.
The task is marked done only when the test passes.
Click Open diff to review the code, the test,
and the ledger line that records who finished the task.
Next, sw-done verifies and closes the increment.
