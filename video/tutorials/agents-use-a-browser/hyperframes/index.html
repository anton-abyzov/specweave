Let agents use a browser,
right beside the thread.
Open Settings, Integrations, and
turn on Agent browser access.
Projects can override it, and it applies
when an agent session next starts.
greet-app serves its demo
page locally, on port 5173.
Ask the coordinator to
check it in the browser
beside the thread, so you can watch.
Open the new thread.
Its agent opens an isolated
tab with the preview_* tools.
Dock the tab beside the thread and
watch it type Ada and press Greet.
The page says Hello, Ada.
To try something
yourself, click Take over.
It's the same tab, and the
agent waits while you drive.
Type Grace, press Enter, then Hand back.
Now ask for a screenshot.
The agent captures the tab as you
left it and shows it in the chat.
