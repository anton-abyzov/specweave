Grok in SpecWithCode: plan, build, review.
In your repo, run specweave init with the generic adapter.
It adds AGENTS.md and eleven SpecWeave skills.
Grok skips project skills in folders it doesn't trust.
In the repo, run grok --trust once.
Signed out? Run grok login first.
Open SpecWithCode. In the account menu, pick Settings, then Providers.
Grok is off by default: click Add provider, pick Grok, existing CLI,
click Next twice, then Add instance.
Add the repo: the plus next to Projects, Local folder, then its path.
A new chat opens.
Pick Grok in the model picker, and set Full access for this demo.
Type a dollar sign, pick sw-increment, and describe the change.
Grok writes spec.md: acceptance criteria and a task with its files and test.
Then send sw-do.
Grok claims the task, changes the code, and runs the test.
The task is marked done only when the test passes.
Click Open diff to review the code, the test,
and the ledger line that records who finished the task.
Next, sw-done verifies and closes the increment.
