One Chrome extension, for every
agent you run in SpecWithCode.
Open Settings, Chrome.
Add to Chrome opens SpecWithCode Browser in the
Chrome Web Store, and Chrome keeps it up to date.
Choose Show pairing code, and copy it.
In Chrome, click the SpecWithCode icon, paste
the code, name this profile Work, and pair it.
Start a chat with GitHub Copilot, and ask
it to check the demo page in your Chrome.
It opens a tab, types Ada, presses
Greet, and reads back Hello, Ada.
In another chat, Codex uses the
same extension, in tabs of its own.
You install it once, for every provider.
Agent tabs stay in the blue SpecWithCode
tab group. Drag a tab out to take it back.
Or press Pause, and no
agent can use this profile.
Get SpecWithCode Browser from the
Chrome Web Store. The link is below.
