# Shared B-roll for SpecWithCode videos

No stretch of a video sits on a plain black or empty dark background. Each stretch carries real footage or photos. Use realistic, licensed stock first, and AI imagery only as a fallback. Put a scrim behind any text that sits over these images.

Each still here is a 1920x1080 frame taken from a Pexels clip. All clips are under the [Pexels license](https://www.pexels.com/license/), which allows free commercial use and modification with no attribution required. The full clips also feed the How SpecWithCode works explainer (see `explainers/how-it-works`).
