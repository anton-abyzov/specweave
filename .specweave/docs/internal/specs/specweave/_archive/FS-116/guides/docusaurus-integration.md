# Docusaurus Integration Guide

This guide explains how to integrate LivingSpec with [Docusaurus](https://docusaurus.io/) to create a browsable, versioned documentation site from your living documentation.

## Prerequisites

- Node.js 18+ installed
- An existing LivingSpec project (`.livingspec/` directory)
- Docusaurus 3.x project (or willingness to create one)

## Quick Start

### 1. Install the Plugin

```bash
npm install @livingspec/docusaurus-plugin
```

### 2. Configure docusaurus.config.js

```javascript
// docusaurus.config.js
module.exports = {
  // ... other config
  plugins: [
    [
      '@livingspec/docusaurus-plugin',
      {
        // Path to your LivingSpec directory
        specsDir: '.livingspec',

        // Output path for generated docs
        outputDir: 'docs/specs',

        // Enable auto-sidebar generation
        autoSidebar: true,

        // Show origin badges for external (E-suffix) items
        showOriginBadges: true,

        // Include AI context summaries
        includeAiContext: true,
      },
    ],
  ],
};
```

### 3. Run the Build

```bash
npm run build
# or for development
npm run start
```

## Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `specsDir` | string | `.livingspec` | Path to LivingSpec directory |
| `outputDir` | string | `docs/specs` | Where to generate docs |
| `autoSidebar` | boolean | `true` | Generate sidebar from structure |
| `showOriginBadges` | boolean | `true` | Show external origin badges |
| `includeAiContext` | boolean | `false` | Include AI context blocks |
| `frontmatterFields` | string[] | `['id', 'title', 'status']` | Fields to include in frontmatter |

## Auto-Generated Sidebar

When `autoSidebar: true`, the plugin generates a sidebar structure matching your LivingSpec hierarchy:

```
Specifications
├── EP-001: Platform Modernization
│   ├── FS-042: User Authentication
│   │   ├── US-001: User Registration
│   │   └── US-002: User Login
│   └── FS-043: Authorization
└── EP-002E: External Initiative 🔗
    └── FS-044E: Imported Feature 🔗
```

### Sidebar Configuration

```javascript
// sidebars.js
module.exports = {
  specsSidebar: [
    {
      type: 'autogenerated',
      dirName: 'specs',
    },
  ],
};
```

## MDX Components

The plugin provides custom MDX components for LivingSpec documents:

### StatusBadge

```mdx
import { StatusBadge } from '@livingspec/docusaurus-plugin/components';

<StatusBadge status="in-progress" />
```

### OriginBadge

```mdx
import { OriginBadge } from '@livingspec/docusaurus-plugin/components';

<OriginBadge source="github" externalId="#42" externalUrl="https://github.com/..." />
```

### AcceptanceCriteria

```mdx
import { AcceptanceCriteria } from '@livingspec/docusaurus-plugin/components';

<AcceptanceCriteria
  items={[
    { id: 'AC-US1-01', description: 'Given valid email...', status: 'passed' },
    { id: 'AC-US1-02', description: 'Given invalid email...', status: 'pending' },
  ]}
/>
```

### HierarchyBreadcrumb

```mdx
import { HierarchyBreadcrumb } from '@livingspec/docusaurus-plugin/components';

<HierarchyBreadcrumb
  items={[
    { id: 'EP-001', title: 'Platform', href: '/specs/EP-001' },
    { id: 'FS-042', title: 'Auth', href: '/specs/FS-042' },
    { id: 'US-001', title: 'Registration' },
  ]}
/>
```

## Versioning

Integrate with Docusaurus versioning for release documentation:

```javascript
// docusaurus.config.js
module.exports = {
  docs: {
    versions: {
      current: {
        label: 'Next',
        path: 'next',
      },
    },
  },
  plugins: [
    [
      '@livingspec/docusaurus-plugin',
      {
        // Generate docs per version
        versionedDocs: true,
        // Sync version with manifest
        useManifestVersion: true,
      },
    ],
  ],
};
```

## Search Integration

The plugin automatically adds metadata for Docusaurus search:

```yaml
---
id: US-001
title: User Registration
tags:
  - authentication
  - user-story
  - status:in-progress
keywords:
  - registration
  - signup
  - account creation
---
```

### Algolia DocSearch

Configure search to index LivingSpec content:

```javascript
// docusaurus.config.js
themeConfig: {
  algolia: {
    appId: 'YOUR_APP_ID',
    apiKey: 'YOUR_API_KEY',
    indexName: 'your-index',
    searchParameters: {
      facetFilters: ['type:spec', 'status:in-progress'],
    },
  },
},
```

## Real-Time Sync (Advanced)

For real-time updates during development:

```javascript
// docusaurus.config.js
plugins: [
  [
    '@livingspec/docusaurus-plugin',
    {
      // Watch for changes and rebuild
      watchMode: process.env.NODE_ENV === 'development',

      // Debounce rebuild (ms)
      watchDebounce: 1000,

      // Files to watch
      watchPatterns: ['**/*.md', '**/metadata.json'],
    },
  ],
],
```

## Troubleshooting

### Build Fails with "Invalid frontmatter"

Ensure all LivingSpec documents have valid YAML frontmatter:

```yaml
---
id: "FS-042"
title: "User Authentication"
status: "in-progress"
---
```

### Origin badges not showing

1. Verify `showOriginBadges: true` in config
2. Check that E-suffix items have `origin`, `source`, `external_id` fields
3. Import the CSS for badges

### Sidebar not updating

Clear the build cache:

```bash
npm run clear
npm run build
```
