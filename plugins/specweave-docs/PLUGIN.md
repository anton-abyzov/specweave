# Documentation Plugin

**Version**: 1.0.0
**Author**: SpecWeave Contributors
**License**: MIT

## Description

Complete documentation ecosystem for technical writers, product teams, and developers. Provides expertise in creating API documentation, tutorials, changelogs, and Docusaurus-powered documentation sites. Includes specification-driven product discovery and stakeholder communication tools.

## Skills

| Skill | Description |
|-------|-------------|
| technical-writing | Expert in API documentation, README files, tutorials, changelog management, and developer documentation with style guides and OpenAPI/Swagger support |
| docusaurus | Docusaurus 3.x framework expert for MDX authoring, theming, versioning, and internationalization |
| spec-driven-brainstorming | DEPRECATED: Use `/sw:brainstorm` (core plugin). Multi-perspective ideation with cognitive lenses |

## Installation

```bash
vskill add vskill --plugin docs
```

## Requirements

- SpecWeave core plugin (sw@specweave)
