# JIRA Plugin

**Version**: 1.0.0
**Author**: SpecWeave Contributors
**License**: MIT

## Description

JIRA integration plugin for bidirectional synchronization between SpecWeave increments and JIRA epics, stories, and subtasks. Provides expert mapping, resource validation, and sync guidance for teams using JIRA for project management.

## Skills

| Skill | Description |
|-------|-------------|
| jira-mapper | Expert mapping of SpecWeave increments to JIRA structure with bidirectional sync and traceability |
| jira-resource-validator | Validates JIRA projects and boards, auto-creates missing resources with per-project configuration |
| jira-sync | Sync guidance for SpecWeave increments with JIRA epics and stories |

## Installation

```bash
vskill add specweave --plugin sw-jira
```

## Requirements

- SpecWeave core plugin (sw@specweave)
- JIRA authentication configured
