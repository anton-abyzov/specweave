# Backend Development Plugin

**Version**: 1.0.0
**Author**: SpecWeave Contributors
**License**: MIT

## Description

Expert backend development capabilities for multiple programming languages and frameworks. Provides specialized expertise for building scalable APIs, optimizing databases, and implementing enterprise patterns. Supports .NET/C#, Node.js/TypeScript, Python, and database optimization across relational and NoSQL systems.

## Skills

| Skill | Description |
|-------|-------------|
| dotnet-backend | .NET/C# backend developer for ASP.NET Core 8+ APIs with Entity Framework Core and enterprise patterns |
| nodejs-backend | Node.js/TypeScript backend developer for Express, Fastify, NestJS, and GraphQL APIs |
| python-backend | Python backend developer for FastAPI, Django, and Flask with async/await support |
| database-optimizer | Expert database optimizer for query performance, indexing strategies, and schema design across PostgreSQL, MySQL, and MongoDB |

## Commands

| Command | Description |
|---------|-------------|
| (Integrated skills - no separate commands) | Skills activate automatically based on context and keywords |

## Installation

```bash
claude plugin install sw-backend@specweave
```

## Requirements

- SpecWeave core plugin (sw@specweave)
