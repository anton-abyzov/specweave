# Mobile Plugin

**Version**: 1.0.0
**Author**: SpecWeave Contributors
**License**: MIT

## Description

Expert-driven plugin for React Native and Expo mobile development. Covers mobile application architecture, the New Architecture (Fabric, Turbo Modules, JSI), environment setup, native modules, device testing, performance optimization, and debugging for iOS and Android platforms.

## Skills

| Skill | Description |
|-------|-------------|
| mobile-architect | React Native and Expo mobile architect specializing in New Architecture, Expo Router, and offline-first patterns |
| react-native-expert | React Native and Expo expert for environment setup, Metro bundler, native modules, device testing, and performance optimization |

## Installation

```bash
claude plugin install sw-mobile@specweave
```

## Requirements

- SpecWeave core plugin (sw@specweave)
- Node.js 20.x or later
- React Native or Expo development environment
