# GitHub Plugin

**Version**: 1.0.0
**Author**: SpecWeave Contributors
**License**: MIT

## Description

GitHub integration plugin for issue standardization, task tracking, multi-repository coordination, and bidirectional synchronization with GitHub Projects. Enables consistent issue formatting, fine-grained progress visibility, and cross-repository organization.

## Skills

| Skill | Description |
|-------|-------------|
| github-issue-standard | Mandatory format standard for GitHub issues with checkable acceptance criteria and consistent metadata |
| github-issue-tracker | Task-level progress tracking via comments, checklists, and labels for fine-grained visibility |
| github-multi-project | Expert organization for monorepo, polyrepo, and parent repo architectures across multiple repositories |
| github-sync | Two-way synchronization between SpecWeave specs and GitHub Projects with push and pull capability |

## Installation

```bash
claude plugin install sw-github@specweave
```

## Requirements

- SpecWeave core plugin (sw@specweave)
- GitHub authentication configured
