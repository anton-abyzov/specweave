# Desktop Plugin

**Version**: 1.0.0
**Author**: SpecWeave Contributors
**License**: MIT

## Description

Desktop application development with Electron and Tauri. Build cross-platform desktop apps with web technologies or Rust backends.

## Skills

| Skill | Description |
|-------|-------------|
| electron | Desktop application development with Electron and Tauri for cross-platform native apps |

## Installation

```bash
vskill add specweave --plugin sw-desktop
```

## Requirements

- SpecWeave core plugin (sw@specweave)
